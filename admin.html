Frontend-режим для GitHub Pages

Кнопка «Сохранить изменения» сохраняет расписание прямо в браузере этого устройства. После сохранения откройте страницу «Расписание» — изменения появятся сразу. Backend не требуется.

Важно: localStorage не синхронизируется между устройствами. Чтобы одно и то же расписание увидели все студенты, используйте «Скачать schedule.js» и замените файл assets/js/schedule.js в GitHub.
