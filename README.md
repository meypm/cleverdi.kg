# Cleverdi — сайт списка студентов

Готовый frontend без backend.

## Что реализовано
- полный список студентов;
- размещение по специальностям;
- 10 карточек специальностей;
- поиск по ФИО;
- фильтр по специальности;
- фильтр по результату;
- проходной балл;
- результат тестирования;
- автоматический итог;
- пагинация по 40 записей;
- адаптация под ноутбук, планшет и смартфон;
- на смартфоне таблица автоматически становится карточками.

## Данные
Все реальные записи находятся в:
`assets/js/students.js`

Сейчас сайт работает полностью локально — достаточно открыть `index.html`.

## Логика результата
- результат >= проходного балла → «Проходной балл набран»;
- результат < проходного балла → «Не набран»;
- если балл отсутствует → «Нет результата».

## Автоматическая справка об обучении
- вариант «для военкомата» удалён;
- студент вводит фамилию или ФИО;
- если совпадений несколько, выбирает нужную запись;
- ФИО и специальность подставляются автоматически из списка;
- формируется предварительный текст справки;
- есть печать и сохранение в PDF через системное окно печати;
- на frontend-этапе документ помечен как демонстрационный и требует подтверждения уполномоченного сотрудника.

## Расписание и объявления

Расписание теперь находится на отдельной странице `schedule.html`. На странице расписания нет поиска студентов и результатов тестирования. Объявление показывается сверху расписания.

Данные расписания вынесены в отдельный файл, чтобы их можно было менять без правки HTML:

`assets/js/schedule.js`

Внутри файла:
- `announcements` — объявления, которые показываются **над расписанием**;
- `lectureNote` и `changeNote` — текст под объявлениями;
- `days` — дни недели и занятия;
- у каждого занятия можно менять `time`, `subject`, `teacher`, `room`;
- `startDate` — дата, указанная в шапке расписания.

После изменения `schedule.js` сохраните файл и обновите страницу в браузере.


## Расписание и объявления
- Объявление редактируется прямо в `schedule.html` в блоке с комментарием `ОБЪЯВЛЕНИЕ — РЕДАКТИРУЙТЕ ТЕКСТ ПРЯМО ЗДЕСЬ`.
- Расписание редактируется в `assets/js/schedule.js`.

## Админ расписания

Откройте `admin.html`.

- Логин: `admin`
- Пароль: `Cleverdi2026!`

Админ-страница позволяет визуально менять дни, группы, занятия, преподавателей и аудитории.
Кнопка «Сохранить предпросмотр» сохраняет изменения только в браузере текущего устройства.
Для публикации на статическом сайте нажмите «Скачать schedule.js» и замените файл `assets/js/schedule.js` на хостинге.

Важно: это frontend-авторизация. Данные входа находятся в клиентском JavaScript, поэтому она не является полноценной серверной защитой. Для безопасного входа и публикации изменений всем студентам нужен backend.


## Frontend-only админка расписания

`admin.html` работает на GitHub Pages без backend. После входа изменения сохраняются в `localStorage` браузера и сразу отображаются на `schedule.html` на том же устройстве. Для публикации одного расписания всем пользователям скачайте из админки новый `schedule.js` и замените `assets/js/schedule.js` в репозитории GitHub.
