# Cleverdi — сайт списка студентов

Готовый frontend без backend.

## Что реализовано
- полный список студентов;
- размещение по специальностям;
- 10 карточек специальностей;
- поиск по ФИО;
- фильтр по специальности;
- фильтр по результату;
- проходной балл;
- результат тестирования;
- автоматический итог;
- пагинация по 40 записей;
- адаптация под ноутбук, планшет и смартфон;
- на смартфоне таблица автоматически становится карточками.

## Данные
Все реальные записи находятся в:
`assets/js/students.js`

Сейчас сайт работает полностью локально — достаточно открыть `index.html`.

## Логика результата
- результат >= проходного балла → «Проходной балл набран»;
- результат < проходного балла → «Не набран»;
- если балл отсутствует → «Нет результата».

## Следующий этап
После утверждения frontend данные можно перенести в backend/API, не меняя визуальную часть.


Добавлены: уведомления, заказ справок, FAQ 24/7.


## Автоматическая справка об обучении
- вариант «для военкомата» удалён;
- студент вводит фамилию или ФИО;
- если совпадений несколько, выбирает нужную запись;
- ФИО и специальность подставляются автоматически из списка;
- формируется предварительный текст справки;
- есть печать и сохранение в PDF через системное окно печати;
- на frontend-этапе документ помечен как демонстрационный и требует подтверждения уполномоченного сотрудника.
